## 0. שני חסמים שנמצאו בבדיקה (17.09)

**מדידה — כבויה לגמרי.** בטבלת `tracking_destinations` בפרוד אין אף שורה, ובחשבון המודעות "הדר אוטומציות" אין פיקסל. התשתית (פיקסל, GA4, Conversions API, ייחוס UTM) בנויה ומחכה. מה צריך:
1. Meta Events Manager → ליצור Dataset (פיקסל) בשם Lessio → להעתיק Pixel ID + ליצור Conversions API access token.
2. Google Analytics → נכס GA4 ל-getlessio.com → להעתיק Measurement ID ‏(`G-...`).
3. `/admin/tracking` → להוסיף את שניהם ולהפעיל.
4. הרשמת בדיקה מלינק עם utm → לוודא שהאירוע הגיע ל-Events Manager.

עד שזה נעשה, לא מעלים מודעות.

**מורה יחיד/ה צריך/ה מספר עסקי נפרד.** החיבור היום תמיד רושם את המספר ב-Cloud API (`registerPhoneNumber` ב-`src/app/(dashboard)/settings/whatsapp/actions.ts`), כלומר המספר יוצא מאפליקציית הוואטסאפ. מצב "אותו מספר גם באפליקציה וגם ב-Lessio" (coexistence של Meta) לא נתמך — זו בנייה נפרדת, לא הגדרה. לכן כל נוסח ליחידים אומר את זה ביושר ומציג את זה כיתרון: קו עסקי נפרד, הקו האישי נשאר אישי.

## 2. מורים יחידים

**המסר:** את מלמדת. את הביטולים, התזכורות והתשלום של סוף החודש מישהו אחר סוגר.
**אין דמואים.** סרטון → דף `/tutors` → הרשמה. שיחה רק עם מי שכבר בניסיון ונתקע.

### 2.1 פוסטים לקבוצות פייסבוק של מורים פרטיים

בלי לינק בגוף הפוסט (רוב הקבוצות מוחקות). לינק רק בתגובה, ורק למי שמבקש. לבדוק את כללי הקבוצה לפני כל פרסום.

**פוסט 1 — "הערב של סוף החודש"**
```
שאלה למורים פרטיים כאן.

כמה זמן לוקח לכם סוף החודש?

אני שואלת כי אצל כל מורה שדיברתי איתה זה נראה אותו דבר. ערב אחד, הוואטסאפ פתוח מצד אחד והיומן מצד שני. מי ביטל ומתי. מי ביטל ברגע האחרון ומגיע לי עליו תשלום. מי עוד לא שילם על החודש שעבר. ואז ההודעות להורים, אחת אחת, עם הסכום.

ותמיד יש ביטול אחד שנשכח, ושיעור אחד שאף אחד לא בטוח אם התקיים.

איך אתם סוגרים חודש? אקסל, פנקס, זיכרון? באמת סקרנית.
```

**פוסט 2 — "הביטול של 21:40"**
```
יום שלישי, 21:40. הודעה מאמא של תלמיד: "היי, מחר לא נגיע, סליחה".

השיעור מחר ב-16:00. לפי המדיניות שלי ביטול בפחות מ-24 שעות מחויב. עכשיו יש לי שתי אפשרויות: לכתוב לה את זה ולהרגיש לא נעים, או לוותר ולהפסיד שיעור.

רוב המורים שאני מכירה מוותרים. לא כי הם לא צודקים, אלא כי אף אחד לא רוצה לנהל את השיחה הזאת.

מה שגיליתי: כשהמדיניות כתובה מראש וההורה רואה אותה ברגע הביטול, ומאשר בעצמו, השיחה הזאת פשוט לא קורית. אף אחד לא מתווכח עם כלל שהוא הסכים לו.

יש לכם מדיניות ביטולים כתובה? וההורים באמת מכירים אותה?
```

**פוסט 3 — "בניתי משהו" (רק בקבוצות שמתירות, ורק אחרי שני הראשונים)**
```
כתבתי כאן בשבועות האחרונים על סוף החודש ועל ביטולים של הרגע האחרון, והתגובות היו מאוד דומות.

אז בגילוי נאות: אני בונה מערכת בדיוק לזה. קוראים לה Lessio. הורה מבטל בוואטסאפ, המדיניות שלך קובעת אם יש חיוב, ההורה מאשר, וזה כבר רשום בחשבון של סוף החודש. תזכורות לשיעורים ובקשות תשלום יוצאות לבד.

שני דברים שחשוב לי להגיד ביושר. היא עובדת על הוואטסאפ הרשמי של Meta, ולכן צריך מספר עסקי נפרד מהמספר האישי. והיא עולה 149 ש"ח לחודש למורה יחיד אחרי 30 יום חינם, בלי כרטיס אשראי.

מי שרוצה לראות, יש סרטון של 75 שניות. כתבו לי ואשלח.
```
