# חיבור Lessio ל-Make (ול-n8n)

מדריך הקמה לספק התשלום `make` — הדרך לסלוק דרך Grow (או כל סולק אחר) בלי לשלם על גישת API ישירה.

> **למה זה קיים:** Grow גובים ₪500 + מע"מ לחודש על גישת API. Grow אישרו במפורש שגישה דרך Make אינה כלולה בחיוב הזה. מנוי Make Core עולה כ-$9 לחודש.

---

## איך זה עובד

```
1. בעל העסק לוחץ "שלח בקשת תשלום" ב-Lessio
2. Lessio ← POST → תרחיש א' ב-Make          "צריך לינק תשלום על 400 ₪"
3. תרחיש א' → Grow → מחזיר קישור
4. תרחיש א' ← Webhook response → Lessio     "הנה הקישור"
5. Lessio שולח את הקישור בוואטסאפ להורה     (כרגיל, בלי שינוי)
6. ההורה משלם → Grow מודיע לתרחיש ב'
7. תרחיש ב' → POST /api/v1/charges/:id/payments → Lessio   "החיוב שולם"
```

שני תרחישים. הראשון מוציא קישור, השני סוגר את החיוב.

---

## שלב 0 — מפתח API

1. ב-Lessio: **הגדרות ← אינטגרציות**
2. **יצירת מפתח**. שם: `תרחיש הסליקה ב-Make`. הרשאות: סמנו **`write`** (וגם `read` אם התרחיש יקרא נתונים).
3. **העתיקו את המפתח מיד.** הוא מוצג פעם אחת בלבד ואי אפשר לשחזר אותו.

בדיקה מהירה שהמפתח חי:

```bash
curl -H "Authorization: Bearer lsk_live_..." https://app.getlessio.com/api/v1/me
```

תשובה תקינה מחזירה את שם הארגון שלכם. אם חוזר `401` — המפתח שגוי או בוטל. אם חוזר `403` עם `feature_unavailable` — התוכנית לא כוללת אינטגרציות (נדרש Advanced).

## שלב 1 — תרחיש א': הוצאת קישור תשלום

**מודול 1 — Webhooks ← Custom webhook**

צרו webhook חדש והעתיקו את הכתובת (`https://hook.eu2.make.com/...`).

Lessio ישלח אליו JSON כזה:

```json
{
  "reference":   "mk_8f3c...",
  "chargeId":    "4a1e...",
  "orgId":       "9b22...",
  "amount":      400,
  "description": "שיעורי אוגוסט",
  "payer": { "fullName": "ישראל ישראלי", "phone": "+972501234567" }
}
```

לחצו **Redetermine data structure** ואז שלחו בקשת תשלום אחת מ-Lessio, כדי ש-Make ילמד את מבנה הנתונים.

**מודול 2 — Grow (או HTTP)**

צרו דף תשלום עם `amount` ו-`description` מהמודול הקודם.

> **חשוב:** העבירו את ה-`reference` לשדה חופשי של Grow (למשל `cField1`). תרחיש ב' יזדקק לו כדי לדעת איזה חיוב נסגר.

**מודול 3 — Webhooks ← Webhook response**

- **Status:** `200`
- **Body:**
  ```json
  {"url": "{{2.paymentUrl}}"}
  ```
  (החליפו ב-שדה הקישור שהמודול של Grow החזיר)
- **Custom headers:** `Content-Type: application/json`

התרחיש **חייב** להחזיר את הקישור באותה קריאה. Lessio ממתין עד 15 שניות ואז מוותר.

מקובלים גם `paymentUrl`, `payment_url`, `link`, `paymentLink`, קינון אחד תחת `data`/`body`, וגם כתובת חשופה בלי JSON.

## שלב 2 — הגדרת הספק ב-Lessio

**הגדרות ← תשלומים**

- **ספק:** `Make / n8n (אוטומציה)`
- **כתובת ה-Webhook:** הכתובת מ-מודול 1

שמרו. עכשיו כל בקשת תשלום מ-Lessio עוברת דרך התרחיש.

---

## שלב 3 — תרחיש ב': סגירת החיוב

**מודול 1 — Webhooks ← Custom webhook**

צרו webhook שני, והגדירו אותו כ-callback בחשבון Grow (או השתמשו במודול Watch של Grow).

**מודול 2 — HTTP ← Make a request**

| | |
|---|---|
| **URL** | `https://app.getlessio.com/api/v1/charges/CHARGE_ID/payments` |
| **Method** | `POST` |
| **Headers** | `Authorization: Bearer lsk_live_...` |
| **Body type** | Raw / JSON |
| **Content type** | `application/json` |

החליפו `CHARGE_ID` ב-`chargeId` שהעברתם דרך השדה החופשי של Grow.

**Body:**

```json
{
  "reference": "{{1.transactionId}}",
  "method": "provider"
}
```

בלי `amount` — Lessio סוגר את מלוא היתרה. אפשר לשלוח `amount` לתשלום חלקי.

## בדיקה מקצה לקצה

1. צרו חיוב בסך **₪1** על תלמיד בדיקה.
2. שלחו בקשת תשלום. ודאו שהקישור בוואטסאפ הוא קישור Grow אמיתי.
3. שלמו ₪1 באמת.
4. ודאו שהחיוב ב-Lessio עבר ל־**שולם**.
5. **הגדרות ← אינטגרציות ← פעילות אחרונה** — אמורה להופיע שורה `200 POST /api/v1/charges/…`.

## פתרון תקלות

| מה קורה | הסיבה |
|---|---|
| "הפעולה נכשלה" בשליחת בקשת תשלום | התרחיש לא ענה תוך 15 שניות, או שלא הוחזר קישור. בדקו ב-Make שמודול Webhook response קיים ומחזיר שדה `url`. |
| `401` בפעילות האחרונה | מפתח שגוי, או שנשלח בלי `Bearer `. |
| `403 forbidden` | למפתח חסרה ההרשאה `write`. צרו מפתח חדש עם ההרשאה. |
| `403 feature_unavailable` | התוכנית לא כוללת אינטגרציות. נדרש Advanced. |
| `404` | ה-`chargeId` שגוי, או שייך לארגון אחר. |
| `409 conflict` | החיוב בוטל או נמחל. יש לפתוח אותו מחדש ב-Lessio. |
| `429` | יותר מ-120 קריאות בדקה למפתח. |
| החיוב לא נסגר, אבל אין שגיאה | תרחיש ב' לא רץ. בדקו שה-callback מוגדר בחשבון Grow. |

**קריאה שחוזרת פעמיים לא מזיקה:** חיוב שכבר שולם מחזיר `200` עם `"alreadyPaid": true` ולא יוצר תשלום כפול. אפשר להפעיל retry ב-Make בבטחה.

## n8n

זהה, בשני הבדלים:

- **Custom webhook** → צומת `Webhook`, עם `Respond` = `Using Respond to Webhook node`
- **Webhook response** → צומת `Respond to Webhook`, עם `Respond With` = `JSON`

---

## אבטחה

- המפתח נשמר ב-Lessio כ-sha256 בלבד — הוא אינו ניתן לשחזור, גם לא על ידינו.
- מפתח `write` יכול לסמן חיובים כשולמו. אל תשתפו אותו ואל תכניסו אותו לתרחיש משותף.
- ביטול מפתח (**הגדרות ← אינטגרציות ← ביטול**) חוסם אותו מיידית. צרו מפתח חדש והחליפו אותו בתרחיש.
- כל קריאה נרשמת ב-**פעילות אחרונה** — שם רואים אם מישהו משתמש במפתח שלא לצורך.
